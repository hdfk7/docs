# 惜缘破军 · 记录与偶然

个人静态网站，用来整理开发笔记、旅行照片和日常记录。文章使用 Markdown 编写，页面由原生 HTML、CSS 和 JavaScript 渲染，无需数据库和前端构建步骤。 HTML、业务 JavaScript、CSS 与日签 JSON 已压缩，浏览器仍直接加载原路径下的文件；修改后需保持语法及页面检查通过。

## 主要功能

- 首页展示最近更新的三篇文章，顶部提供文档与简历入口，博客和资源链接放在页面底部。
- 首页首屏在介绍文案下方有一段“精选”：一篇主推 + 两篇副推，桌面两列、手机纵向堆叠，内容由索引里的 `featured` / `featuredOrder` 指定。
- 文档列表支持分类筛选，以及按标题、简介、标签和文件名搜索。
- 文章按发布时间倒序排列，阅读页提供目录和上一篇、下一篇入口。
- Markdown 支持代码块、表格、图片和 HTML 视频；使用 Marked 解析，DOMPurify 过滤不安全内容。
- 所有正文图片支持点击放大；相邻的多个纯图片或视频块可按原顺序组成相册，底部用一排小圆点翻页（圆点 6px、点击区 28×40px，上下留白收紧），右侧显示页码，不自动播放，支持滑动和方向键切换，切换时自动暂停非当前视频。
- 视频使用原生播放器，支持手动播放、手机内联播放和自适应宽度。
- 手机分类栏将“全部”独占一行，其余四个分类按两行两列对称排列，文章列表和阅读页适配窄屏。
- 首页提供每日一签，结果与当天抽取状态保存在浏览器本地。

## 分类标准

按文章的主要用途选择一个分类。分类由 `app/app.js` 的 `DOCUMENTS` 数据中的 `category` 字段决定，文章统一保存在 `md/`，不要求按分类建立子目录。“全部”是汇总入口，不是文章分类。

| 分类 | 内容范围 | 典型例子 |
| --- | --- | --- |
| 开发笔记 | 编程、架构、数据库、部署运维等技术实践，侧重方案、过程和原理 | Spring Boot 框架、Kubernetes 部署、MySQL 时间分组统计 |
| 旅行记录 | 行程、沿途见闻、照片、视频和旅行攻略 | 四姑娘山、西安与华山、理小路 |
| 生活随笔 | 日常记录、个人感受、读书心得和阶段总结 | 生活片段、读书感想、年度回顾 |
| 工具备忘 | 工具使用、常用命令、参数和配置速查，主要用于日后回查 | Arthas 命令、Docker Swarm 速查、Git 操作 |

开发笔记与工具备忘的区分：完整讲解一个技术方案、实现过程和原理，放开发笔记；主要用于查命令、查参数、查操作步骤，放工具备忘。文章涉及多个主题时，以主要阅读目的决定分类，用 `tag` 补充技术关键词。

## 新增与维护文章

1. 将 UTF-8 编码的 Markdown 文件放入 `md/`，正文以一级标题开头。
2. 将图片或视频放入 `static/` 对应目录。
3. 在 `app/app.js` 的 `DOCUMENTS` 数组中增加索引数据。
4. 检查文章链接、分类、目录、图片和视频在电脑及手机上的效果。

### 标题与目录规则

- 一级标题用于文章名称，不重复进入阅读页目录。
- 二级标题用于主要章节，是目录统一展示的层级。
- 三级及以下标题用于章节内的细分内容，仅在正文展示，避免目录过长。
- 简历与普通文章使用同一套目录规则；目录点击后跳转到对应章节。

索引字段说明：

| 字段 | 用途 |
| --- | --- |
| `file` | 相对于 `md/` 的文章文件名 |
| `path` | 可选，自定义文章路径；存在时优先于 `md/` 加文件名 |
| `slug` | 文章链接中的稳定短码，使用现有函数生成 |
| `publishedAt` | 北京时间，格式为 `YYYY-MM-DD HH:mm:ss.SSS` |
| `title` | 列表和阅读页显示的标题 |
| `category` | 分类名称 |
| `tag` | 技术关键词或旅行日期等简短标签 |
| `summary` | 首页和文档列表显示的简介 |
| `featured` | 可选，写 `true` 表示进首页精选，最多取 3 条 |
| `featuredOrder` | 可选，精选内的排序序号，1 为主推；不写时排在最后 |

发布时间决定首页、列表和文章切换的顺序，仅调整数组位置不会改变显示顺序。旅行发生日期可以写在正文和标签中，与文章发布时间分别维护。

精选只影响首页那一段，不参与列表、搜索和上一篇／下一篇。顺序按 `featuredOrder` 排，不走发布时间——否则最新发布的一篇会自动顶成主推。没有一条带 `featured` 时，整块自动隐藏。

```js
{file:'某篇文章.md',featured:!0,featuredOrder:1}
```

### 生成 slug

沿用 `app/app.js` 中的 `slugFor()`，不要手工编造短码。该函数以 `hdfk7-docs-2026|` 加文章路径为输入计算哈希，再转换为至少六位的 36 进制字符串。

在网站浏览器控制台执行以下代码即可获得新文件对应的短码：

```js
slugFor({file:'新文章.md'})
```

生成时不要传入已有 `slug`，否则函数会直接返回该值。将结果写入新文章的索引，并检查与其他文章是否重复。未填写 `slug` 时，页面也会按相同规则计算。

已发布文章保留现有 `slug`，以维持链接稳定；如需移动或重命名文件，同步更新文件路径，保留原有短码。

### 图片

```md
![图片说明](../static/travel/example.jpg)
```

路径替换成项目中实际存在的图片。正文图片可点击放大，`alt` 文字同时用作图片说明。

站内所有图片地址都由 `app/app.js` 顶部的 `ASSET_BASE` 拼接，代码里用 `assetUrl()`，模板里用 `data-asset`；`ASSET_BASE` 留空则走本站 `/static/`。正文 md 写仓库相对路径 `../static/...`，首页数据写 `static/...`，都不带域名。

### 图片地点

正文图片的拍摄地点显示为图片左下角的浮标，点开放大后在地点单独一行。地点按以下顺序取：

1. 图片的 `title` 字段，适合写到具体点位：

```md
![索桥的桥面，尽头是石砌的碉楼。](../static/travel/2025-09-07-jiuhuangshan/IMG_8756.JPEG "九皇山 · 观音崖")
```

2. 没写 `title` 时，查 `app/app.js` 的 `PHOTO_PLACES`，键是「图集目录/文件名」，值精确到点位（如 `瓦屋山 · 鸳鸯池`）。当前逐张维护 89 张正文图片的地点，结合原图 EXIF GPS、Photon 候选地标距离、照片内容与游记章节核对，展示只保留景区、景点或街道名称，不附省、市、区县前缀；只能确认到地区的照片保留简短地名。地图返回的最近地标只作线索，不能直接等同于拍摄点；没有原图定位的照片只写来源可确认的景区或线路。
3. 还没有条目时，按图集目录退到景区名，对应表是 `TRAVEL_PLACES`，目前包括峨眉山、四姑娘山、华山、九皇山、理小路、瓦屋山、都江堰、街子 · 元通。

首页轮播的图片不从目录推断，在 `app/app.js` 的 `HOME_GALLERY` 里给对应条目写 `place:'瓦屋山'`；没写就不显示浮标。浮标在对应图片加载完成后才出现，加载中和加载失败都不显示。浮标不参与点击，放大仍由图片本身接管；地点不写进 `alt`，避免读屏重复。

### 视频

将视频放入 `static/videos/` 等目录，在 Markdown 中写入：

```html
<video controls playsinline preload="metadata" aria-label="视频说明">
  <source src="/static/videos/demo.mp4" type="video/mp4">
  你的浏览器不支持视频播放。
</video>
```

以上路径是写法示例，需要添加自己的视频文件。可在 `<video>` 上增加 `poster="/static/videos/demo-cover.jpg"` 设置封面；也可引用外部 HTTPS 视频直链。

推荐 MP4 容器、H.264 视频编码和 AAC 音频编码。页面会启用播放控件与手机内联播放，移除自动播放属性；默认只预加载视频元信息。`![说明](视频.mp4)` 属于图片语法，不能播放视频。

首页底部寄语上方的旅行照片轮播，图片、宽高、说明和地点统一在 `app/app.js` 的 `HOME_GALLERY` 里维护，模板只留 `.home-travel-gallery` 容器，由 `renderHomeGallery()` 生成图片后交给 `initGalleries`；当前收录从下载目录精选的 64 张照片（原有 32 张加本次新增 32 张），每条均填写详细拍摄地点，与正文采用相同核对规则；混合行程按照片逐张区分，不把文件夹名直接当成拍摄地。数组为空时容器自动隐藏。有数据时每次进入或刷新首页重新随机排列，不连续重复首图，每 5 秒切换一张、可暂停（播放／暂停按钮仅显示图标，居中放在左右箭头之间，页码独立放在说明行右侧，控件行上下内边距收紧为 0／2px，保留至少 40px 点击区和无障碍名称），悬停、键盘焦点位于相册内、放大预览、页面隐藏或相册位于视口外时暂停，尊重减少动态效果偏好；正文相册保持原顺序、手动切换。电脑端最宽 880px（正文宽度 960px 内居中），手机使用紧凑的 4:3 展示区，照片完整显示，比例留白沿用同图模糊背景。图片保存在 `static/home-gallery/日期/原文件名.jpg`，原始照片保持不变，站点副本最长边 1920px。维护时按 `{src,width,height,alt,place,takenAt}` 追加条目，地点显示沿用左下角浮标和放大弹窗。雪峰原图所在目录为 `2023-11-19-毕棚沟`，因此标为毕棚沟；混合行程中的铜锅照片定位到宝兴县硗碛藏族乡，不猜测具体店铺；城墙照片修正为茂县叠溪镇教场村，不再标作中国古羌城。街子镇凤栖山一带的照片与元通古镇分开标注。精确 GPS 和反查原始数据仅保存在本地核对记录，不写入公开图片数据。

维护时，文档与相册复用 `makeElement()` 创建元素，单图与相册共用 `appendPhotoPin()` 生成地点浮标；连续媒体按一次顺序遍历分组，视频暂停逻辑统一处理。源码仍直接在原路径维护，无新增依赖或构建步骤。

`app/app.js` 顶部集中维护资源和服务地址、日签与轮播计时、固定分类，以及文档、简历、首页照片和地点映射；运行时缓存与交互状态保留在后面的逻辑区。压缩 JSON 只移除多余空白，保留原有字段、顺序和文本内容。

## 本地预览

在项目根目录启动静态文件服务，例如已安装 Python 时运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000/`，文档列表地址为 `http://127.0.0.1:8000/#/docs`。项目使用从站点根目录开始的资源路径，应通过 HTTP 服务访问，并部署在网站根目录。

可通过浏览器开发者工具切换手机尺寸，检查分类排列、搜索框、文章和媒体宽度。

## 部署到 Nginx

在目标 Linux 服务器准备 Bash、Git、rsync、find、md5sum、sed、sort、xargs、cat、cut 等工具，以及部署目录写入权限，然后运行：

```bash
bash /脚本所在目录/deploy.sh
```

脚本的默认配置：

| 项目 | 默认值 |
| --- | --- |
| 远程仓库 | `https://gitee.com/hdfk7/docs.git` |
| 分支 | `master` |
| 部署目录 | `/usr/share/nginx/default` |
| 缓存目录 | 执行脚本时当前目录的 `hdfk7-deploy/` |

执行过程：

1. 检查部署目录和缓存目录路径。
2. 缓存中没有有效 Git 仓库时重新克隆。
3. 已有仓库时还原所有跟踪文件，并删除未跟踪、被忽略的文件及目录，再同步远程分支。缓存仅用于部署，不应放入需要保留的个人文件。
4. 将项目同步到缓存中的 `payload/`，排除 Git 管理文件，清理上次残留内容。
5. 根据前端 JS、CSS 内容生成资源版本号，仅修改待部署副本，保持缓存仓库干净。
6. 把 `payload/` 镜像同步到部署目录：目标有、源没有的文件被删除，其余文件按大小和修改时间跳过，只传变更部分；同步后核对两边文件数，不一致则中止并提示。结束后保留 `repo/` 和 `payload/`，下次继续复用。

脚本先进入缓存仓库，再执行 Git 命令。部署结果与源完全一致，部署目录内多余文件会被删除；运行前应确认该目录专用于本站。静态文件更新无需重载 Nginx。

当前脚本对部署目录做了固定路径校验，如需更换目标，须同时修改配置和对应校验。

## 爬虫访问规则

根目录 `robots.txt` 默认使用以下规则，请求所有遵守协议的爬虫停止抓取全站，包括文章和静态资源：

```text
User-agent: *
Disallow: /
```

现有部署脚本会将该文件同步到网站根目录，GitHub Pages 也会直接发布。发布后访问 `https://你的域名/robots.txt`，确认返回 HTTP 200 和上述规则；本地修改不会立即影响线上。

这是一项自愿遵守的抓取规则，不能拦截忽略规则的恶意爬虫，也不保证已有网址从搜索结果中消失。强制防采集或请求限流需要在 Nginx 或 CDN 层另行配置；公开仓库和外部图床的访问不受本站规则保护。协议说明见 [Google robots.txt 文档](https://developers.google.com/search/docs/crawling-indexing/robots/intro)。

### 图片与视频混合相册

连续的纯图片、原生 `<video>` 或纯媒体段落会自动合成同一相册；中间出现正文或标题时分组结束。至少包含两项媒体才会生成相册，单项保留原有展示方式。

图片可点击放大，视频保留原生播放、进度和全屏控件。相册外观为单张展示，说明行右侧显示页码，下面一排小圆点用于翻页；不设左右箭头和进度条，也没有播放按钮。正文相册按原顺序手动翻页，不自动播放。切换到其他项时自动暂停视频，视频不会自动播放；在视频上使用方向键时保留播放器自身行为。

```html
<img src="/static/travel/photo-a.jpg" alt="沿途风景">
<video controls playsinline preload="metadata" aria-label="旅途片段">
  <source src="/static/videos/travel.mp4" type="video/mp4">
</video>
<img src="/static/travel/photo-b.jpg" alt="山间暮色">
```

以上为写法示例，请替换为实际媒体文件。原有连续 Markdown 图片写法也保持支持。

### 页面地址

正式入口为首页 /、列表 /#/docs、文章 /#/docs?d=短码；分类筛选使用 category 参数。未知文件路径显示独立 404 页面，Nginx 与 GitHub Pages 均可使用 404.html。

### 首页每日寄语

顶部主题句固定，底部由 app/app.js 中的 DAILY_QUOTE_URL 配置接口，留空时显示原句。接口需允许浏览器跨域读取，返回格式为 code: 1、data: [{content: '句子'}]。按访问者本地日期每天选一句并缓存，刷新和站内切换保持一致；请求失败、超时或数据为空时，当天回退到原句。修改接口地址会重新获取。浏览器存储不可用时在当前页面会话内保持一致。

### 首页轮播手动操作

自动播放开启时，手动滑动或点击上一张／下一张后重新计时，约 5 秒后继续轮播；手指按住滑动区域期间暂停计时。点击暂停后，滑动和翻页均保持暂停，只有再次点击播放才恢复。触摸点击翻页按钮后释放按钮焦点，键盘操作仍保留焦点及阅读暂停。

新增首页照片逐张排除人物正脸、合影和人物全身远景，保留风景、动物、文物及物件。地点结合原图定位、来源与既有正文交叉核对；仅能确认地区时使用简短地区名，不附省、市、区县前缀，不猜具体机位。

鼠标或触摸打开放大图时轮播临时暂停；关闭后焦点仍返回原图，并重新计时约 5 秒后继续播放。此前主动暂停的仍保持暂停；键盘打开后的阅读焦点、鼠标悬停等暂停条件继续生效。

首页轮播说明行右侧显示拍摄日期与页码，如 `2023.09.03 · 12 / 64`，随照片同步更新。`HOME_GALLERY.takenAt` 优先核对原图 EXIF 拍摄日期，使用 `YYYY-MM-DD`；没有原始拍摄日期时仅写可确认的行程年月 `YYYY-MM`。窄屏说明较长时，日期和页码整体换到下一行并靠右；正文相册不追加日期。
