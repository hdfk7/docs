# IPTV Android｜手机与电视直播播放器

IPTV Android 是一款支持手机和 Android TV 的直播播放器，最低支持 Android 8.0。它可以导入 M3U 订阅，将同一频道的多条线路合并，播放失败时自动尝试其他线路。界面使用 Kotlin 和 Jetpack Compose，播放器使用 Media3 ExoPlayer。

项目源码见 [GitHub · hdfk7/iptv-android](https://github.com/hdfk7/iptv-android)。

```bash
git clone https://github.com/hdfk7/iptv-android.git
```

## 订阅源、频道和收藏

应用预设「国内精选」「综合频道」「全球频道」三个订阅入口，也可以自行添加、编辑或删除 HTTP(S) M3U 订阅。每次只启用一个源，切源时优先显示该源的本地缓存。国内精选按类别分组，央视频道按台号排列。

同名频道会归并到一起，重复的线路地址会去掉。观看时可以手动选线或重连，也可以让播放器在线路失败时自动尝试下一条。线路排序参考本机记录的稳定性、分辨率、帧率和出画耗时。

收藏会保留频道的来源和线路。来自不同订阅源的同名频道，可以在「收藏」里合并观看。频道侧栏的「最近」按源记录最多 20 个已开始播放的频道，方便接着看。

## 手机触控与电视遥控器

**手机**轻点画面即可唤出底栏。频道面板在竖屏时从底部展开，横屏时从左侧展开。点按频道换台，长按查看今日节目单。

**电视**默认全屏。按确认键、右键或 INFO 唤出底栏，按左键打开频道侧栏，菜单键直达「更多」。侧栏打开时，左右键切换分组，上下键浏览频道，按确认换台。收起侧栏和菜单后，上下键可直接换台。

手机和电视的底栏都提供频道、播放／暂停、收藏和「更多」。管理订阅、刷新、切线、重连、音量和设置都在「更多」里。

## 节目单、缓存与更新

节目单支持订阅自带的 XMLTV 地址，也支持为订阅源单独指定地址。频道侧栏可以查看正在播和接下来播什么，今日节目单按设备时区显示当天排期。

进入前台时会刷新订阅，也可以在「更多」里手动刷新。刷新失败时继续保留已有列表和收藏。需要代理时，可在设置里配置 HTTP 代理，订阅下载和视频播放共用该配置。应用版本更新则从「设置 → 检查应用更新」单独进入。

应用提供订阅入口和播放功能，频道列表与直播内容由订阅源提供。

## 1.3.3 开发手记

### 出画之后，再显示正在播放

线路连上后，画面可能还没出来。1.3.3 把「正在播放」的显示时机放到了实际出画之后。等待期间优先显示缓存画面，生成预览时跳过黑帧。首帧超时或播放卡住，就继续尝试其他线路。

启动频道可选「上次观看」或「列表首个」。手机中央的播放按钮和播放、暂停图标也一起调整。1.3.3 加了「视频铺满屏幕」，打开后等比放大，超出屏幕的部分会被裁掉，重启后仍保留选择。

### 遥控器焦点与返回位置

电视面板用一个原生焦点接收遥控器按键，内部记录当前选中的分组或条目。切组后按下键，优先选中该组内正在播放的频道，否则落在第一项。浏览期间继续播放当前频道。

从节目单或设置子页返回时，恢复进入前的选择。编辑源地址或代理时，按确认才进入输入框，收起键盘后可以继续用方向键移动。

### 今日节目单与横屏表单

这一版修正了跨日排期和重复的「正在播」标记，也把排期计算移到后台，减少滚动和遥控器操作时的界面更新。

手机横屏留给表单的高度有限，源管理、编辑源和 HTTP 代理的布局因此一起调整。设置页则把代理与更新放在一组，把启动频道和铺满开关放在另一组，手机和电视沿用同样的排列。
