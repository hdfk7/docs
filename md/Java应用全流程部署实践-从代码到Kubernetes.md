# Java应用全流程部署实践：从代码到Kubernetes

## 项目概述

本文基于开源项目 [hdfk7/hdfk7-boot](https://github.com/hdfk7/hdfk7-boot) 的 `next` 分支，概述一个典型 Java Spring Boot 应用从本地开发、容器化到最终部署至 Kubernetes 集群的完整流程。
该示例项目提供了一个可操作的实践样板，涵盖了现代云原生 Java 应用部署的核心环节。相关的配置文件、脚本和资源均位于该仓库的 `example` 文件夹中。

## 核心流程总览

整个部署流程可概括为以下七个核心阶段，形成一个完整的 CI/CD 闭环：

1. **本地开发与代码提交**：基于 Spring Boot 框架进行功能开发与测试。
2. **持续集成 (CI)**：借助阿里云云效等工具，在代码推送后自动执行构建与单元测试。
3. **容器镜像构建**：使用 Docker 将应用及其依赖打包为标准化的容器镜像。
4. **镜像推送**：将构建成功的镜像推送到容器镜像仓库（如 阿里云容器镜像服务 ACR）。
5. **Kubernetes 环境准备**：搭建或配置一个 Kubernetes 集群。
6. **应用部署与配置**：编写 Kubernetes 资源清单（如 Deployment、Service、Ingress），将应用部署到集群。
7. **持续部署 (CD)**：配置自动化流程，在镜像更新后自动或手动触发集群内的应用滚动更新。
